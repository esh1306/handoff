# Scanned objects

Nine objects from **Google Scanned Objects** (Downs et al., 2022), converted to MuJoCo by
Kevin Zakka in https://github.com/kevinzakka/mujoco_scanned_objects.

- MJCF conversion: MIT, see LICENSE-MJCF-MIT.txt

The catalogue video2sim uses (names, sizes, which can be grasped) is ../objects.json.
